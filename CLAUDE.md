# WSM Website — Cloudflare project

## Commit / release conventions

- **Commit messages are just an incrementing number** (e.g. `1`, `2`, `3`). No description, no body.
- **Never include a `Co-Authored-By:` footer or any Claude attribution** in commit messages.
- Pick the next number by looking at the most recent numeric commit in `git log` and incrementing.
